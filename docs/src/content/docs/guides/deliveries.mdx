Every time Sparrow sends an event to a webhook endpoint, it creates a delivery record. You can query delivery status, view attempt history, and manually retry failed deliveries.

## Delivery Lifecycle

```
pending → delivering → success
                     → failed (retryable) → retrying → delivering → ...
                     → failed (permanent)
```

## List Deliveries

<Tabs>
  <TabItem label="Connect-RPC (curl)">
    ```bash
    curl -X POST http://localhost:8080/webhook.DeliveryService/ListDeliveries \
      -H "Content-Type: application/json" \
      -d '{
        "webhookId": "YOUR_WEBHOOK_ID",
        "namespace": "default",
        "limit": 20
      }'
    ```
  </TabItem>
  <TabItem label="Go (Connect-RPC)">
    ```go
    resp, err := deliveryClient.ListDeliveries(ctx, connect.NewRequest(&pb.ListDeliveriesRequest{
        WebhookId: webhookID,
        Namespace: "default",
        Limit:     20,
    }))
    for _, d := range resp.Msg.GetDeliveries() {
        fmt.Printf("Delivery %s: status=%s attempts=%d\n",
            d.GetId(), d.GetStatus(), d.GetAttemptCount())
    }
    ```
  </TabItem>
</Tabs>

## Get Delivery Details

```bash
curl -X POST http://localhost:8080/webhook.DeliveryService/GetDeliveryStatus \
  -H "Content-Type: application/json" \
  -d '{
    "deliveryId": "YOUR_DELIVERY_ID",
    "namespace": "default"
  }'
```

## View Delivery Attempts

Each delivery may have multiple attempts (initial + retries). View the full attempt history:

```bash
curl -X POST http://localhost:8080/webhook.DeliveryService/GetDeliveryAttempts \
  -H "Content-Type: application/json" \
  -d '{
    "deliveryId": "YOUR_DELIVERY_ID",
    "namespace": "default"
  }'
```

Each attempt includes:
- HTTP status code
- Response body (truncated)
- Response time in milliseconds
- Error category (if failed)
- Timestamp

## Retry a Delivery

Manually retry a failed delivery:

```bash
curl -X POST http://localhost:8080/webhook.DeliveryService/RetryDelivery \
  -H "Content-Type: application/json" \
  -d '{
    "deliveryId": "YOUR_DELIVERY_ID",
    "namespace": "default"
  }'
```

This creates a new delivery attempt regardless of the current status or retry count.

## Retry Logic

Sparrow uses exponential backoff for automatic retries:

- **Retryable errors**: Server errors (5xx), timeouts, connection refused, network errors
- **Non-retryable errors**: Client errors (4xx), DNS failures, TLS errors

See [Error Classification](/sparrow/reference/error-classification/) for the complete taxonomy.
