<CardGrid stagger>
  <Card title="Dual-Protocol API" icon="setting">
    gRPC on `:50051` and Connect-RPC (HTTP/JSON) on `:8080`. Same service implementations, zero duplication.
  </Card>
  <Card title="Event-Driven Fan-Out" icon="rocket">
    Push one event, deliver to many subscribers. Async processing via River (Postgres-backed job queue).
  </Card>
  <Card title="Payload Transforms" icon="pencil">
    Go `text/template` engine with 22+ built-in functions. Transform payloads per-subscription before delivery.
  </Card>
  <Card title="Health Tracking" icon="approve-check-circle">
    Event-sourced health state machine with 24-hour lookback. Per-webhook success rates, p95 latency, error breakdown.
  </Card>
  <Card title="HMAC Signatures" icon="warning">
    Stripe/GitHub-style `HMAC-SHA256` signing on every delivery. Constant-time verification examples in Go, Node.js, and Python.
  </Card>
  <Card title="Zero Dependencies" icon="laptop">
    Just PostgreSQL. No Redis, no Kafka, no RabbitMQ. River uses your existing Postgres for job queuing.
  </Card>
</CardGrid>
