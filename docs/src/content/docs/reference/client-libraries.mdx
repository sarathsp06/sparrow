Sparrow provides generated client stubs for Go, JavaScript/TypeScript, and Python. Two protocols are supported:

| Protocol | Port | Recommended For |
|----------|------|----------------|
| **Connect-RPC** (recommended) | 8080 | HTTP/JSON, browsers, proxies, standard `net/http` |
| **gRPC** | 50051 | HTTP/2 streaming, existing gRPC infrastructure |

:::tip
For step-by-step integration guides with full examples, see:
- [Go SDK Guide](/sparrow/guides/go/)
- [Python SDK Guide](/sparrow/guides/python/)
- [TypeScript SDK Guide](/sparrow/guides/typescript/)
:::

## Go

The Go client is part of the main Sparrow module. Import directly:

<Tabs>
<TabItem label="Connect-RPC (Recommended)">

```bash
go get github.com/sarathsp06/sparrow
go get connectrpc.com/connect
```

```go
import (
    "connectrpc.com/connect"

    pb "github.com/sarathsp06/sparrow/proto"
    pbconnect "github.com/sarathsp06/sparrow/proto/protoconnect"
)

httpClient := http.DefaultClient
client := pbconnect.NewWebhookServiceClient(httpClient, "http://localhost:8080")

resp, err := client.RegisterWebhook(ctx, connect.NewRequest(&pb.RegisterWebhookRequest{
    Namespace: "default",
    Url:       "https://example.com/webhook",
    Events:    []string{"order.created"},
    Active:    true,
}))
```

</TabItem>
<TabItem label="gRPC">

```bash
go get github.com/sarathsp06/sparrow
go get google.golang.org/grpc
```

```go
import (
    "google.golang.org/grpc"
    "google.golang.org/grpc/credentials/insecure"

    pb "github.com/sarathsp06/sparrow/proto"
)

conn, err := grpc.NewClient("localhost:50051",
    grpc.WithTransportCredentials(insecure.NewCredentials()),
)
defer conn.Close()

client := pb.NewWebhookServiceClient(conn)
resp, err := client.RegisterWebhook(ctx, &pb.RegisterWebhookRequest{
    Namespace: "default",
    Url:       "https://example.com/webhook",
    Events:    []string{"order.created"},
    Active:    true,
})
```

## JavaScript / TypeScript

Connect-RPC client for browsers and Node.js:

```bash
npm install @bufbuild/protobuf @connectrpc/connect @connectrpc/connect-web
```

Copy `client/js/connect/proto/` into your project, then:

```typescript
import { createClient } from "@connectrpc/connect";
import { createConnectTransport } from "@connectrpc/connect-web";
import { WebhookService } from "./lib/sparrow/webhook_pb";

const transport = createConnectTransport({
  baseUrl: "http://localhost:8080",
});

const client = createClient(WebhookService, transport);

const resp = await client.registerWebhook({
  namespace: "default",
  url: "https://example.com/webhook",
  events: ["order.created"],
  active: true,
});
```

## Python

gRPC client (no Connect-RPC plugin available for Python):

```bash
pip install grpcio protobuf
```

```python
import grpc
from proto import webhook_pb2, webhook_pb2_grpc

channel = grpc.insecure_channel("localhost:50051")
stub = webhook_pb2_grpc.WebhookServiceStub(channel)

response = stub.RegisterWebhook(
    webhook_pb2.RegisterWebhookRequest(
        namespace="default",
        events=["order.created"],
        url="https://example.com/webhook",
        active=True,
    )
)
print(f"Webhook ID: {response.webhook_id}")
```

## Available Services

| Service | Description |
|---|---|
| `WebhookService` | Register, update, pause/resume webhooks |
| `EventService` | Push events, register event types, re-push |
| `SubscriptionService` | Manage webhook-event subscriptions |
| `DeliveryService` | Query delivery history, retry deliveries |
| `HealthService` | Webhook health metrics and summaries |

## Regenerating Clients

All client code is auto-generated from `webhook.proto`:

```bash
make generate
```

This produces stubs in `client/go/`, `client/js/`, and `client/python/`.
