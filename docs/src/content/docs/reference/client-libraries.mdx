Sparrow provides generated client stubs for **Go**, **JavaScript/TypeScript**, and **Python**. See the SDK guides for full integration walkthroughs:

- [Go SDK](/sparrow/getting-started/go/) -- Connect-RPC and gRPC, error handling, HMAC verification
- [Python SDK](/sparrow/getting-started/python/) -- gRPC client, async support, signature verification
- [TypeScript SDK](/sparrow/getting-started/typescript/) -- Connect-RPC for browsers and Node.js

## Regenerating Clients

All client code is auto-generated from `webhook.proto`:

```bash
make generate
```

This produces stubs in `client/go/`, `client/js/`, and `client/python/`.
