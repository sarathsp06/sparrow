Get the application URL:

  {{- end }}
{{- else }}
  kubectl port-forward svc/{{ include "sparrow.fullname" . }} 8080:{{ .Values.service.httpPort }}
  Then open: http://localhost:8080
{{- end }}

API reference (Scalar):
  Then open: http://localhost:8080/docs

{{- if .Values.postgresql.enabled }}

PostgreSQL shell:
  kubectl exec -it {{ include "sparrow.fullname" . }}-postgresql-0 -- psql -U {{ .Values.postgresql.auth.username }} -d {{ .Values.postgresql.auth.database }}

NOTE: The built-in PostgreSQL uses a PersistentVolumeClaim that persists after
`helm uninstall`. To fully clean up, run:
  kubectl delete pvc data-{{ include "sparrow.fullname" . }}-postgresql-0
{{- end }}
