# Go

The Go verifier is the `pkg/signature` module, not a copy-paste file:

```bash
go get github.com/sarathsp06/sparrow/pkg/signature
```

See [`pkg/signature`](../../../pkg/signature/signature.go) and the
[verification guide](https://sarathsp06.github.io/sparrow/guides/verify-signatures/).
`run-vectors.sh` runs the shared vectors against it.
